Статическая и динамическая память
Статической памятью мы не управляем в отличии от динамической памяти, то есть сами удаляются
динамическая память выделсяется с помощью new, 
2 проблемы
1) если не записан указатель наружу, объявлен внутри
if(){
    int *ptr = new int;
}
после if указателя потеря, но память все еще allocated - MEM LEAK
2) двойной delete - ошибка 
   nullptr можно сколько угодно
   правильно
     delete ptr;
     ptr = nullptr
     delete ptr - не является ошибкой
"-" динамической памяти
  - медленная
  - непредсказуемо медленная
можно выделять не только одну ячейку
int* arr = new int[n] - размера n,
удаление delete[] arr;
многомерный дин массив
двумерный - массив указателей
int** mtx = new int*[rows];
for i in range(columns):
    mtx[i] = new int[columns];
в отличии от статик массива, они расположены рандомно
удаление с конца
for i in range(columns):
    delete[] mtx[i]
delete[] mtx;
