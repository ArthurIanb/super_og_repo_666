static переменные глобальные на уровне где они объявлены
в функции при первом вызове присвоивается ноль, а при остальных * игнорируется

int funk(){
    static int x = 0; * 
    ++x;
}
при каждом вызове x увеличивается

Глобальные переменные - bad practice
Лучше static
---------------------------------------------------------------------------
static внутри файла замыкает переменную

file1.h

static int x;
